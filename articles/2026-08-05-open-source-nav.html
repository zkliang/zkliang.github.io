工具怎么选

开源软件导航站怎么挑：我常用的 6 个「软件界豆瓣」

2026-08-05 · 约 8 分钟阅读

先说一个你可能也踩过的坑：想装个压缩软件，百度一搜「7zip 下载」，排在最前面的不是官网，而是一排「高速下载」「安全下载」「立即下载」——点下去蹦出三四个不认识的捆绑，装完发现浏览器主页被改了、桌面多了两个弹窗助手。

我后来学乖了：找软件别直接搜，先去「软件导航站」看一眼。好的导航站本质上是帮你做减法的编辑——它把经过筛选的、真正免费开源的软件列出来，还顺手告诉你「这个和那个比，谁更适合你」。

一、为什么需要软件导航站，而不是直接搜

搜索引擎对「下载」类词的商业化很重，前几条常常是下载站和广告。而一个靠谱的软件导航站，价值恰恰在于「反商业化噪音」：它不靠给你推捆绑赚钱，靠的是「清单经得起检验」。

但导航站也分门派，有的重「全」、有的重「精」、有的重「对比」。下面 6 个是我真正常用、且风格互补的，按「你当下想要什么」对号入座。

二、6 个我常用的软件导航 / 发现站

1. FreeNav（就是本站）

先交代立场：我做这个站，就是因为烦透了捆绑和追踪。它的选品底线是开源优先、真免费无暗坑、不偷偷上报你的行为。目前收了 近百款软件，按 11 大使用场景分好类，还配了几个深度专题，比如本地 AI 怎么选、新人装机清单。

适合谁：想要「装得安心、不被追踪」的普通用户，尤其是小白。你不用懂开源，我们替你把过关。

2. fmhy（Free Media Heck Yeah）

一个由社区维护的巨型清单，覆盖软件、流媒体、下载工具、去广告方案等，英文为主但信息密度极高。它的强项是「这个商业软件有什么免费 / 开源平替」——你想摆脱某个付费工具时，先来这搜。

适合谁：愿意啃英文、想找「替代方案」和「资源合集」的进阶用户。

3. AlternativeTo

它的玩法很直接：输入一个软件名，它列出「大家还在用什么替代它」，每条都有社区投票和平台标注。比如搜「Notion」，它会按「开源 / 免费 / 跨平台」给你排好。

适合谁：想给某个闭源软件找开源平替的人，决策前看一眼很省时间。

4. Slant

「做 X 最好的工具是什么？」这类问题，Slant 用社区投票 + 论据来回答，而不是算法推荐。比如「最好的免费视频剪辑软件」，每个候选下面都有人写为什么选 / 不选。

适合谁：做选择困难症、需要从「对比理由」里做决定的人。

5. GitHub Topics & Awesome 列表

如果你本身会一点技术，GitHub 的 topic 搜索和各类「Awesome-X」清单是不可替代的——它们由开发者维护，更新快、可信度高。比如搜 awesome-selfhosted，能找到一堆可自托管的开源工具。

适合谁：开发者、能读英文文档、想追最新开源项目的人。

6. Product Hunt

偏向「新品首发」，每天有一批新工具上架、社区投票。好处是你能第一时间知道「有没有更好用的新东西」，坏处是良莠不齐，需要自己鉴别。

适合谁：喜欢尝鲜、关注效率工具趋势的人。

三、怎么挑，才不会越看越乱

别同时盯着 6 个站。给你一个简单映射：

· 想「装得省心、不被坑」→ FreeNav；
· 想「找某个软件的平替」→ AlternativeTo / fmhy；
· 想「在几个候选里做决定」→ Slant；
· 想「追最新的开源项目」→ GitHub Topics；
· 想「看今天有什么新鲜工具」→ Product Hunt。

它们不是竞品，是互补的。我自己的习惯是：先用 FreeNav 兜底日常需求，遇到冷门需求再切到 fmhy 或 AlternativeTo 挖。

四、一个小提醒

导航站再好，也只是「线索」不是「保证」。点进任何下载链接前，先看域名是不是软件官网（很多开源项目的官网是 项目名.org/.io，而不是某个下载站），再确认没有「下载器 / 高速下载」这类二次打包。我们把这些坑写进了每篇专题，比单篇清单更耐用。

写在最后

软件导航站的价值，不是「软件多」，而是「你信它能替你把过关」。上面 6 个里，有的重全、有的重精、有的重对比——你按自己的场景挑 1~2 个长期用，比收藏 20 个书签有用。

如果你想要一个「不追踪你、人工精选、中文友好」的起点，从 FreeNav 的工具清单开始就行。也欢迎在 GitHub 上给我投稿好用的软件——我们挑得很严，但从不闭门造车。
